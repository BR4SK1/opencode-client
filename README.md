# opencode-client

Minimal Next.js (App Router) + TypeScript + Material UI starter.

## Prerequisites

- Node >= 20.9
- pnpm

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

## Build & Quality

```bash
pnpm build
pnpm lint
```
